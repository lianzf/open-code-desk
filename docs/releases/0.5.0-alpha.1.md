# OpenCode Desk 0.5.0-alpha.1

发布日期：2026-08-02

阶段：D - AI 辅助调试闭环

Git Tag：`v0.5.0-alpha.1`

## 阶段目标

在阶段 C 的真实 Node.js/TypeScript DAP 调试基础上，完成用户主导的“捕获异常 → 脱敏预览 →
交给 AI 分析 → 读取相关代码 → 生成修复 Diff → 用户批准 → 显式重新调试验证”闭环。该入口不得
绕开现有上下文预算、文件变更审批、命令审批或调试控制权限。

## 更新内容

### 调试上下文快照

- 新增 `DebugContextService`、领域模型和独立 `debug-context.ipc.ts`。
- 仅允许从真实 `paused` 调试会话收集上下文，并校验目标会话属于同一工作区。
- 支持暂停位置、源码片段、异常、调用栈、局部变量、监视表达式、控制台输出、运行配置、Git Diff、
  最近文件变更和 `package.json` 依赖 11 类分区。
- 每个分区有独立标题、Token 粗估、脱敏计数、截断状态和默认选择状态。
- 预览绑定 session、workspace、conversation、暂停指纹和内容摘要，10 分钟过期；只缓存已脱敏版本。

### 用户审核与 Agent 修复

- 调试面板在暂停时提供“交给 AI 分析”按钮；未配置模型、无会话或已有请求运行时不可发起。
- 预览对话框展示将发送的完整文本，用户可逐分区勾选，确认前不调用 Provider。
- 确认后仅把所选分区保存为当前会话的高优先级 `diagnostic` ContextItem。
- Agent 复用现有 ContextBuilder、只读文件工具和 Provider 流式循环，不增加调试专用越权工具。
- 修复只能形成 FileChange 和 Monaco Diff；用户未批准、未应用时磁盘内容保持不变。
- 应用修复后程序仍保持暂停，必须由用户显式点击“重新调试”验证。

### 安全与可靠性

- 增强通用凭据脱敏，覆盖密码、Token、API Key、Client Secret、Private Key、数据库 URL、Bearer、
  常见云密钥形状和带 userinfo 的 URL。
- 对敏感调试变量名执行值无关脱敏，即使值不符合已知密钥格式也不会进入预览。
- 原始变量、异常、Git Diff 和源码只在收集调用栈内短暂存在；Renderer、预览缓存和 SQLite 均只接收
  已脱敏、已限长版本。
- 附加行为写入不含内容的审计事件；审计元数据只记录会话 ID、分区数和脱敏计数。
- 修复 js-debug 原生 restart 在未捕获异常暂停时可能不返回的问题：用户点击重新调试后，先幂等清理
  旧 adapter/debuggee，再按同一份已批准配置建立新的 DAP 会话。

### IDE 使用痛点改进

- 用户无需在调试器、终端、编辑器和 AI 对话之间手工复制异常、栈帧和变量。
- 发送范围在调用模型前可见、可选且有 Token/脱敏提示，避免“IDE 悄悄上传全部调试状态”。
- AI 读取文件和生成 Diff 的过程继续显示在工具记录与变更审核中，不产生不可追踪的直接覆盖。
- 修复完成后保留清晰的重新调试动作，避免模型自行重启服务打断当前调试现场。

## 数据库升级

本阶段不增加数据库迁移，继续使用 `PRAGMA user_version = 10`。用户确认的已脱敏调试快照复用既有
`context_items` 表，并以 `debug:<sessionId>` 作为同一会话内的来源键；API Key、原始变量、原始异常
和未选择分区不会写入 SQLite。

## 已知限制与下一阶段

- 完整调试和 AI 修复闭环当前只覆盖 Node.js/TypeScript；Java、Python、C/C++、.NET、Go、Rust 和
  浏览器 Adapter 尚未接入。
- 当前快照面向单个暂停会话；跨多个前后端服务、worker 或微服务的因果关联尚未实现。
- AI 修复 E2E 证明异常消失，但不会自动判定所有业务语义正确；用户仍应运行相关测试。
- 当前实现普通行断点；条件、命中次数、日志、函数、异常策略和数据断点尚未完成。
- 调试/运行面板支持显示与隐藏，但暂不支持拖动调整高度。
- 未签名安装包仅用于开发验证；正式发布仍需 Windows 签名、macOS 签名/notarization 和干净设备验收。
