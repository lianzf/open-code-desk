# OpenCode Desk 0.4.0-alpha.1

发布日期：2026-08-02

阶段：C - Node.js/TypeScript 真实 DAP 调试

Git Tag：`v0.4.0-alpha.1`

## 阶段目标

在阶段 B 的项目识别、运行配置和受管进程基础上，建立不依赖日志推断的真实调试闭环。用户能够
审核准确启动快照、设置断点、命中暂停、查看线程/调用栈/变量、执行单步和求值，并在停止或退出时
可靠清理调试器与被调试进程。

## 更新内容

### DAP 与可扩展调试架构

- 新增 DAP framing/client，支持并发请求、事件、超时、断开与反向 `startDebugging` 请求。
- 新增 `RuntimeDebugAdapterProvider`、`DebugAdapterSession` 与 `DebugAdapterRegistry`；新增语言只需
  实现独立 Adapter 并注册，不修改调试会话主流程。
- 首个 Adapter 使用官方 `vscode-js-debug 1.117.0`，来源、MIT 许可证和入口 SHA-256 均有记录。
- js-debug 作为 Electron `extraResources` 随安装包分发，不依赖用户全局安装 VS Code。

### 真实 Node.js/TypeScript 调试

- 从结构化运行配置创建独立调试提案，经逐次审批后启动 DAP 会话。
- Monaco gutter 支持普通行断点的添加、启用、禁用、删除与验证状态回写。
- 命中断点后自动打开工作区源码、居中并高亮当前执行行。
- 支持线程、调用栈、栈帧切换、作用域、局部/嵌套变量与持久化监视表达式。
- 支持继续、暂停、Step Over、Step Into、Step Out、运行到光标、重启与停止。
- 独立调试控制台显示程序/适配器输出，支持当前栈帧表达式求值和异常详情。

### 安全、持久化与恢复

- 审批摘要绑定配置版本、结构化命令、工作区、环境元数据、环境文件摘要和风险原因。
- runtime、program 与源码路径必须位于授权工作区；调试启动使用参数数组和 `shell: false`。
- 输出、异常、变量和求值结果在进入 Renderer 或 SQLite 前按运行时 Secret 值脱敏并限长。
- SQLite migration 10 新增 `debug_sessions`、`debug_breakpoints` 与 `debug_watches`。
- 历史恢复不自动重放调试命令；停止、终止、异常和应用退出会清理本应用拥有的调试进程。
- 固定 js-debug 入口 SHA-256：
  `50EBF42EBA65B673677866B2FCC1BC82C4D6AAFE2BDB67A2EA76A3A7A89D1902`。

### IDE 使用痛点改进

- 代码、断点、调试状态、变量和控制台集中在同一工作台，减少在 AI 聊天与外部调试器之间复制信息。
- 断点明确区分 pending、verified、unverified、disabled 和 error，避免只有图标却没有真实协议状态。
- 启动失败显示实际配置、风险、状态与可读错误；调试信息按线程/栈帧按需加载，避免一次展开全部变量。
- 首次和每次调试都先审核实际启动内容，避免 IDE 自动运行来源不明的项目脚本。

## 数据库升级

应用启动时自动从 `PRAGMA user_version = 9` 迁移到版本 10。迁移只新增调试会话、断点和监视表，
不修改既有工作区、Provider、会话、工具、文件变更、命令、运行配置或运行记录。用户无需手工操作。

## 已知限制与下一阶段

- 完整 DAP 调试当前只覆盖 Node.js/TypeScript；Java、Python、C/C++、.NET、Go、Rust 和浏览器
  Adapter 尚未接入。
- 当前实现普通行断点；条件、命中次数、日志、函数、异常策略和数据断点尚未完成。
- 调试/运行面板支持显示与隐藏，但暂不支持拖动调整高度。
- 阶段 D 将实现用户显式选择的“调试上下文 → 脱敏预览 → AI 分析 → 修复 Diff → 审批 → 重新调试”。
- 未签名安装包仅用于开发验证；正式发布仍需 Windows 签名、macOS 签名/notarization 和干净设备验收。
