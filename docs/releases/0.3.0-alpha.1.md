# OpenCode Desk 0.3.0-alpha.1

发布日期：2026-08-01

阶段：B - 受管项目运行与审批执行

Git Tag：`v0.3.0-alpha.1`

## 阶段目标

在阶段 A 的项目识别和运行配置基础上，建立独立、可审批、可停止、可恢复的 IDE 项目运行闭环。
用户必须先看到真实 executable、参数、工作目录、环境变量元数据和风险原因；批准后主进程才允许
启动项目进程。普通项目运行不冒充 DAP 调试能力。

## 更新内容

### 受管运行执行

- 新增 `RunExecution` 领域模型和 `pending_approval`、`starting`、`running`、`stopping`、
  `stopped`、`completed`、`failed`、`rejected` 状态。
- `RunExecutionService` 负责提案、批准、拒绝、启动、停止、重新运行、查询和关闭清理。
- `RunProcessSupervisor` 独立管理本应用启动的进程、PID、输出、退出与进程树终止。
- 重新运行会创建新的执行和批准记录，不重放旧批准。

### 审批与命令安全

- 审批摘要绑定 execution、workspace、配置版本、executable、runtime args、args、工作目录、
  环境变量公开投影、环境文件摘要、风险等级和风险原因。
- 运行使用结构化参数与 `shell: false`，拒绝提权、命令解释器拼接、路径越界和阻断级风险。
- 环境文件限制在工作区内且最大 1 MiB；批准后文件内容变化会使执行失败并要求重新审核。
- 敏感环境变量只从系统安全凭据存储按引用读取，不进入 Renderer、SQLite 快照或日志。

### 输出、历史与恢复

- stdout/stderr 以流事件实时显示，输出中的实际 Secret 在显示和落库前脱敏。
- 对单次执行设置持久化字节上限，超限时保留可见尾部并标记 `outputTruncated`。
- SQLite migration 9 新增 `run_executions`，保存命令安全快照、风险、审批、PID、退出码、错误和时间线。
- 应用重启后可查看历史；异常中断的活动记录会恢复为明确失败状态，不伪报仍在运行。
- 应用退出时停止并清理本应用拥有的运行进程。

### 桌面体验

- 工作台顶部增加运行配置选择、运行、停止、重新运行和状态显示。
- 增加运行配置编辑器，支持 executable、参数、工作目录、普通/敏感环境变量和输出目标。
- 增加审批对话框，显示完整运行快照与风险原因。
- 增加运行输出面板，显示实时输出、历史、PID、退出码、截断和错误状态。

### Linux 系统凭据质量门禁

- CI 启动独立 D-Bus 与 GNOME Keyring，并用 `secret-tool` 先验证 Secret Service 真实读写。
- Electron E2E 显式移除 Playwright 的 `basic`/mock keychain 启动参数。
- 在应用进入 ready 前恢复 CI 请求的 `gnome-libsecret`，测试直接断言 Electron 实际后端为
  `gnome_libsecret`，因此不会用不安全后端伪造通过。

## 数据库升级

应用启动时自动从 `PRAGMA user_version = 8` 迁移到版本 9。迁移新增 `run_executions` 表，不修改
既有工作区、Provider、会话、工具、文件变更、命令或运行配置数据。用户无需手动操作数据库。
