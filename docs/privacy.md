# 隐私与本地数据说明

OpenCode Desk 是本地优先桌面应用。项目文件、会话、审批、运行/调试历史和本地崩溃报告默认保存在用户设备上；应用没有内置广告、行为分析或远程遥测服务。

## 哪些数据会离开设备

| 场景                             | 发送对象                                 | 可能包含的内容                                                             | 用户控制                                                  |
| -------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------- |
| 模型连接测试、模型列表和 AI 对话 | 用户选择的 Provider Base URL             | API Key/敏感 Header、模型 ID、对话，以及用户选择或工具获准读取的项目上下文 | 用户创建 Provider、选择模型并主动发起请求；生成过程可停止 |
| Agent 工具循环                   | 同一 Provider                            | 有界工具结果，例如文件片段、Git 摘要、诊断或命令结果                       | 文件边界、外部目录授权、命令审批和 Diff 审核分别生效      |
| 更新检查与下载                   | `electron-updater` 配置的 GitHub Release | 当前版本、平台和更新请求所需的标准网络信息                                 | 仅在已安装版本中由用户发起检查/下载，不自动安装           |
| 打开外部链接                     | 用户点击的 HTTPS 页面                    | 浏览器产生的标准请求信息                                                   | 必须由用户点击；应用只允许受支持的外部协议                |

远程 Provider 会按其自身隐私政策处理收到的数据。配置自定义服务前应确认服务运营者、数据驻留、训练使用和保留政策。远程自定义服务必须使用公网 HTTPS；只有解析到本机回环地址的开发服务可以使用 HTTP。应用阻止 URL 内嵌账号、重定向携带凭据以及访问私网/保留地址。

## 本地保存内容

Electron 的 `app.getPath('userData')` 目录保存：

- `open-code-desk.sqlite` 及其 WAL/SHM：工作区引用、Provider 非敏感配置、会话、消息、任务、工具调用、审批、审计、运行/调试历史、断点、设置和本地崩溃记录。
- `change-artifacts/`：待审核内容、原始快照和回滚所需 Artifact；文件名使用不可猜测引用并执行完整性校验。
- Electron/Chromium 自身需要的缓存和本地状态。

默认目录通常是：

- Windows：`%APPDATA%\OpenCode Desk`
- macOS：`~/Library/Application Support/OpenCode Desk`
- Linux：`~/.config/OpenCode Desk`，若设置了 `XDG_CONFIG_HOME` 则位于该目录下

准确位置由 Electron 和操作系统决定。排障或迁移时应先完全退出应用，再整体备份用户数据目录，避免只复制 SQLite 主文件而遗漏 WAL/SHM。

## API Key 和敏感值

API Key 与敏感自定义 Header 先由 Electron `safeStorage` 使用操作系统安全能力加密，再以密文写入本地数据库；Renderer、普通 IPC 响应、日志和配置导出不会回读明文。Linux 必须提供 Secret Service 或 KWallet，检测到 `basic_text`/未知后端时应用拒绝保存。

对话、项目文件和终端输出本身仍可能包含业务秘密。日志、审计、Provider 错误、崩溃详情和 AI 调试上下文会执行已知 Secret 脱敏与长度限制，但任何自动脱敏都不能替代用户在发送前审阅上下文。

## 崩溃报告与日志

“保存本地崩溃报告”默认启用，但 `uploadToServer` 固定为 `false`，报告不会自动上传。报告只保留有界、脱敏的原因、进程类型、版本和诊断字段。审计日志记录操作类别、规范化目标和结果，不记录完整文件内容、完整命令环境或密钥。

如果需要向维护者提供排障材料，优先分享界面中的脱敏错误、审计项、崩溃报告和复现步骤。不要直接发送 SQLite 数据库、`change-artifacts`、项目源码或操作系统凭据目录。

## 删除、卸载与保留边界

- 界面中的“删除会话”当前是软删除：它从历史列表隐藏，但相关行仍可能留在本地数据库中，以保持引用和恢复一致性。
- 卸载应用不保证删除用户数据目录；这是为了避免升级/重装丢失数据。
- 若要彻底清除本机数据，应先退出应用、确认不再需要备份，然后删除整个 OpenCode Desk 用户数据目录。该操作不可恢复，也会删除会话、配置、审计、断点、历史和加密后的 Secret。
- 项目工作区文件不存放在用户数据目录中；删除应用数据不会删除项目，但已经批准并应用到项目的文件修改仍保留在项目内。

当前版本没有云端账户、跨设备同步或服务端数据删除接口。使用远程 Provider 产生的数据删除请求必须直接向对应服务商提出。
